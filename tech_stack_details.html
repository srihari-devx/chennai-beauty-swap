4. Backend Infrastructure (BaaS)

Powered by Supabase (@supabase/supabase-js: ^2.96.0), managing the API queries, authentication flows, and object assets:

PostgreSQL Database: Hosts core schema tables: profile configurations, swap listings, message records, article updates, and user feedback logs.
Supabase Auth: Manages identity authentication, session states, and secure One-Time Passcode (OTP) verifications.
Row-Level Security (RLS): Guards all database access inside PostgreSQL, validating user privileges per action.
Supabase Storage: Secure storage buckets holding item swap images and product photos.
Edge Functions (CLI v2.84.4): Deno backend script functions: setup-admin (administrative access setup), send-otp (secure hashed OTP generator), and delete-user (account purging handler).
